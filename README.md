# Huddle

Intégration responsive d’une page de présentation de Huddle à partir de la maquette Figma incluse dans le dépôt. La page présente une plateforme pour créer et animer une communauté en ligne.

## Mise en page

- Sur mobile le texte et les illustrations s’empilent
- Sur les écrans plus larges l’introduction passe en deux colonnes et les illustrations alternent entre la droite et la gauche dans les trois sections
- Un appel à l’action invite à créer une communauté avant les liens de contact du pied de page

## Technologies utilisées

- HTML pour structurer la page
- CSS avec Flexbox pour l’introduction et Grid pour disposer les sections en deux colonnes
- Polices Open Sans et Poppins hébergées dans le dépôt

## Voir le projet en local

Ouvre `index.html` dans ton navigateur. La page fonctionne sans installation ni JavaScript.
